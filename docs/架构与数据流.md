# 架构与数据流（一页纸）

> English version: [architecture.md](architecture.md)

## 进程与端口

| 谁 | 地址/文件 | 说明 |
|---|---|---|
| DSH web | `127.0.0.1:8080` | 主服务。**先绑端口、后挂路由**——窗口期 `/` 返回 404，所以"就绪"必须以 200 为准 |
| DSH 桥 | `127.0.0.1:8788` | 无障碍 App 起的回环服务，token 在 `~/.dsh-bridge-token`(600)。**不需要网络** |
| 页面任务面板后端 | `127.0.0.1:8787` | `tools/dsh-tasksd`，token 在 `~/.dsh-tasks-token`(600)，只有白名单里的脚本/命令能跑 |
| 文件面板 RPC | DSH 内 `/__dsh__/filepanel/rpc` | 页面插件用它读写**绝对路径**文件（相对路径会被判"不在工作区"） |
| 沙箱第二实例 | `127.0.0.1:8099` | 自检用；必须 `DSH_WEB_EXTRA="--patch ~/.smoke/patch.yml"` 且 `--patch` 写在 `--port` 之前 |

## 三条"我能用手机"的路径（互相独立，界面上一律分开）

```
① 无障碍桥   droid-sock ──▶ 8788 ──▶ DSH 桥 App ──▶ 无障碍 API
             不需要网络；vivo 回收 App 后会掉线（常态），靠带 token 的广播唤醒（2s~40s）
② adb 无线   droid / droid-sock ──▶ 127.0.0.1:5555 ──▶ adbd
             需要"可用的 Wi-Fi 网络"（不只是开关）；重启手机后必须人工再开一次无线调试
③ 页面遥控   dsh-control ──▶ ~/.dsh-look-cmd.json ──▶ 页面插件的 2 秒轮询 ──▶ 浏览器
             只影响 DSH 页面本身，不碰系统
```

## 一次"启动 DSH"的完整数据流

```
小组件/控制台 App
   └─▶ common.sh: dsh_start()
         ├─ 真就绪判定：日志出现 token 行 → curl 该 URL 跟随跳转得 200 → 进程活着
         ├─ 启动互斥锁 ~/.dsh-boot-<port>.lock（同 pid 幂等；pid 死了或目录 5 分钟没动即视为陈旧）
         └─ 无实例时清 ~/.dsh/.credentials.yaml.lock
               （dsh-atomic-write 的等待上限只有 2 秒；`kill -9` 会留孤儿锁 → 之后每次启动都失败）
   └─▶ bridge_wake（带 token 的广播）
   └─▶ tasksd_ensure（127.0.0.1:8787）
   └─▶ publish_status（写 Download/dsh/状态/{status.json,status.txt}）
```

## 状态是怎么汇总到界面上的

```
tools/dsh-status-pub            （采集：DSH/桥/adb/锁/任务尾）
   ├─ 不带 --json：写 status.json + status.txt（给小组件、页面用）
   └─ --json：只打 stdout（给控制台 App 用；**这条路径不写文件**）
        └─▶ App 的 TaskResultReceiver → Last.setStatus → 界面渲染
```
> 注意上面这条分支：`--json` **不写文件**。别拿 `status.json` 的时间戳判断
> "App 那次刷新到底跑了没有"——这是实测踩过的坑（详见 `docs/DSH运维笔记.md` 补三十二续）。

## 装 APK 的数据流（这台机器特有的流程）

```
tools/dsh-install-apk
   ├─ dsh-auth-pass digits  ← ~/.dsh-auth-pass(600)；未授权直接退出 3
   ├─ am start -a VIEW file://<临时 ASCII 路径> -t application/vnd.android.package-archive
   ├─ 点「本次允许使用权限」（不留长期授权）
   ├─ 那行小字「…您可授权本次安装」的**蓝色后半段** ← 用 dsh-find-blue 按像素颜色找
   │      （它不在无障碍树里；系统文案有两种版式，段落 y≈1135/1255）
   ├─ 「锁屏密码验证」→ 6 位数字键盘（坐标从无障碍树里现取）
   └─ 复核：再开一次同一 APK，必须显示「已安装相同版本（x.y）」才算真装上
```
