# 术语表

一个动作，全仓库只用一个词：要么是本项目定义的（软停 / 强杀 / 桥 / 通道 …），要么是行业标准译名。
改文档、写 UI 文案、起变量名前先对一遍；新词先加进这里再用。

> 规则和三类禁用词见 [CONTRIBUTING.md](../CONTRIBUTING.md) §十三。

## 一、停止与重启

| 术语 | 定义 | 不要写成 |
|---|---|---|
| 软停 | 发 `SIGTERM`，让进程自己退出；不升级为强杀 | 优雅退出 / 优雅停 / 优雅停止 / graceful shutdown |
| 强杀 | 用 `kill -9` 直接结束进程，不等它退出 | 强行关闭 / 强制停止 / 硬杀 |
| 软重启 | 组件 `4`：软停 → 备份 → 等端口释放 → 启动（不关窗口、不动别的进程） | 平滑重启 |
| 硬重启 | 组件 `6`：软停 → 逐个强杀 → 关旧窗口 → 启动（插件改动后用这个） | 完全重启 / 彻底重启 |
| 紧急停止 | 组件 `0`：撤销 AI 对手机的控制（桥 + 回环 token + adb 无线调试）；之后要恢复得自己来 | 一键撤销 / 急停 |

## 二、三条通道

| 术语 | 定义 | 不要写成 |
|---|---|---|
| 桥 | 无障碍 App + 回环 `127.0.0.1:8788` 的服务；`dsh-bridge` 操作它，不需要网络 | 无障碍服务（那是 Android 的系统概念） |
| adb 通道 | 无线调试 + adbd，走 `127.0.0.1:5555`；需要可用的 Wi-Fi | 调试桥 / usb 调试 |
| 页面遥控 | `dsh-control` → `~/.dsh-look-cmd.json` → 面板每 2 秒轮询；只动 DSH 页面，不碰系统 | 远程控制 |
| 通道 | 上面三条的统称；界面上一律分开，不合并成一个开关 | 链路（只有真讲网络链路时才用"链路"） |

## 三、界面与组件

| 术语 | 定义 | 不要写成 |
|---|---|---|
| 小组件 | `~/.shortcuts/tasks/` 里由 Termux:Widget 跑的 12 个脚本（英文名 + 中文名各一份） | 组件（会跟界面控件混） |
| 任务 | 控制台 App 里对同一批脚本的称呼（`tools/dsh-tasksd` 按白名单执行） | 作业 / job |
| 控件 | 三处界面上的按钮 / 开关 / 状态灯 | 组件 |
| 面板 | 页面插件在 DSH 页面上的那块 UI（手机面板 / 文件面板） | 插件（插件是载体，面板是它的界面） |
| 状态灯 | 只读的通道状态指示：绿 = 正常，黄 = 过渡，红 = 异常，灰 = 未启用 | 指示灯 / 信号灯 |

## 四、数据与产物

| 术语 | 定义 | 不要写成 |
|---|---|---|
| 状态包 | `dsh-backup` 产出的 `dsh-state-*.tar.gz`：会话、设置、插件清单、笔记 | 快照 |
| 完整快照 | `dsh-snapshot` 产出的 `dsh-full-*.tar.zst`：整个 Termux prefix + 运行时（**含凭据**） | 全量备份 / 状态包 |
| 交付目录 | `Download/dsh/`，用 `dsh-out` 按扩展名归类；唯一投递口 | 输出目录 / 下载目录 |
| 运维笔记 | `~/DSH运维笔记.md` 与 `docs/DSH运维笔记.md` 两份，内容保持一字不差 | 日志（日志是 `*.log`）/ 日记 |
| 生成链 | 源 → 生成产物 的三条链：`ui/controls.json`、`ui/theme.json`、`i18n/zh.json` | 流水线 / pipeline |
| 门禁 | 出包或提交前必须全绿的自检脚本（`tools/ui-controls check`、`tools/i18n-audit` …） | 校验（泛指检查时写"检查"） |

## 五、其它

| 术语 | 定义 | 不要写成 |
|---|---|---|
| 软链 | symlink；profile 里指回运行时的那批链接（被 pnpm 剪掉会让 `/plugins/??…` 404） | 符号链接 / 软连接 |
| 回环 | loopback，即 `127.0.0.1` | 本地网络 / localhost（写地址时直接写 `127.0.0.1`） |
| 自看 | `dsh-selflook`：把 DSH 页面渲成 PNG 给自己看 | 截图（那指 `dsh-screen` / adb `screencap`） |
| 对齐 | 只用于排版（左对齐 / 右对齐）和几何（取基准） | 对一下 / 拉齐；讲两边一致时写"一致 / 一一对应" |
| 闭环 | 不单独用；写清循环（例：量一次 → 拖一次 → 再量） | 闭环 / 形成闭环 / 打通闭环 |
